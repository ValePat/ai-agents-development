# Security & AI Safety Guidelines

This document defines the mandatory safety procedures and current security status of the AI Agents project.

---

## 🛡️ AI Agent Safety Procedures

### 1. Sensitive Data Protection
> **Never expose secrets, credentials, or personal data to any AI model.**
- **Environment Files**: Do not pipe or pass `.env` files directly to an AI assistant.
- **API Keys**: Ensure no keys are present in your prompt context.
- **Anonymization**: Before sharing logs, anonymize all names, emails, and IP addresses.

### 2. Context Management
- **Topic Isolation**: Clear chat history when switching to a different topic to reduce noise and token cost.
- **Exclusion Files**: Use `.geminiignore` or equivalent to prevent large/sensitive files from being included in context.

### 3. Validation of AI Output
- **No Blind Execution**: Never run AI-generated shell commands or scripts without manual review.
- **Sandboxed Execution**: Always use the `backend/sandbox/` directory for agent file operations.

## 🔍 Security Audit (April 2026)

**Status**: ✅ PASS (with recommendations)

### Core Security Features:
- **Secret Management**: API keys are restricted to `.env` (excluded via `.gitignore`).
- **CORS Policy**: Restricted to `localhost:3000` (must be updated for production).
- **Sandboxing**: MCP server enforces a `SAFE_DIR` boundary (`sandbox/`).
- **Code Execution**: Only predefined tools are executable; no arbitrary Python execution allowed.

### Recommendations:
1. **Production CORS**: Explicitly restrict `allow_origins` to your production domain.
2. **Audit Logging**: Implement persistent logging of all tool calls for post-hoc auditing.
3. **Frontend Sanitization**: Ensure the UI escapes HTML/Markdown in agent responses to prevent XSS.

## 🚫 Context Exclusion List

The following are **never** to be passed to an AI assistant:
- **Secrets**: `.env`, `*.key`, `*.pem`, `credentials.json`
- **Dependencies**: `node_modules/`, `venv/`, `__pycache__/`
- **Build Artifacts**: `dist/`, `build/`, `.next/`
- **Logs & DBs**: `*.log`, `*.sqlite`, `*.sql`
