# Deployment Guide: AI Agent Training Stack

This guide provides step-by-step instructions to deploy the **ai-agent-training** stack for free using Vercel and Render.

## 🚀 Tech Stack Overview
- **Frontend**: Next.js 15+ (App Router)
- **Backend**: FastAPI (Python)
- **Agent Framework**: `smolagents` (Hugging Face)
- **Model Provider**: OpenRouter (LLM Abstraction)

---

## 1. Backend Deployment (Render)
**Platform**: [Render.com](https://render.com/) (Free Instance)

### Steps:
1. Create a new **Web Service** on Render.
2. Connect your GitHub repository.
3. Set the **Root Directory** to `backend`.
4. **Build Command**: `pip install -r requirements.txt`
5. **Start Command**: `python main.py` (or `uvicorn main:app --host 0.0.0.0 --port $PORT`)
6. **Environment Variables**:
   - `OPENROUTER_API_KEY`: Your key from OpenRouter.
   - `MODEL_ID`: (Optional) e.g., `openrouter/google/gemini-2.0-flash-exp:free` for zero cost.

## 2. Frontend Deployment (Vercel)
**Platform**: [Vercel.com](https://vercel.com/) (Hobby Tier)

### Steps:
1. Create a new project on Vercel.
2. Connect your GitHub repository.
3. Set the **Root Directory** to `frontend`.
4. **Environment Variables**:
   - `NEXT_PUBLIC_API_URL`: Your Render backend URL (e.g., `https://your-app.onrender.com`).

## 🛠 Required Code Tweaks
Before your final push, ensure these changes are made to handle production traffic:

### A. Update CORS (backend/main.py)
Update the origins to allow your Vercel domain:
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:3000",
        "https://your-frontend-name.vercel.app"
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### B. Dynamic API URL (frontend/components/ChatInterface.tsx)
Replace the hardcoded `localhost` string with an environment variable:
```typescript
const API_URL = process.env.NEXT_PUBLIC_API_URL || "http://localhost:8000";

// In handleSendMessage:
const response = await fetch(`${API_URL}/api/chat`, { ... });
```

## 🌟 Alternative: Hugging Face Spaces
Since the backend uses `smolagents`, you can deploy the entire stack as a **Docker Space** on Hugging Face:
1. Create a new Space with the **Docker** SDK.
2. Create a `Dockerfile` in the root that installs both Node.js and Python.
3. Use a process manager like `supervisord` or a simple shell script to run both servers simultaneously.
