## 🛠 Development Workflows

### Rebuilding Services
If you modify `requirements.txt`, `package.json`, or a `Dockerfile`:
```bash
# Rebuild and restart a specific service
docker-compose up -d --build backend
docker-compose up -d --build frontend
```

### Accessing Containers
To run commands *inside* the running containers (e.g., for debugging):
```bash
# Backend Shell
docker-compose exec backend /bin/bash

# Frontend Shell
docker-compose exec frontend /bin/sh
```

### Database/File Management
The `sandbox` directory is synced between your host and the backend container:
- **Local Path**: `./backend/sandbox/`
- **Container Path**: `/app/sandbox/`

## ☁️ Cloud Deployment

### Backend Deployment (Render)
**Platform**: [Render.com](https://render.com/) (Free Instance)

1. Create a new **Web Service** on Render.
2. Connect your GitHub repository.
3. Set the **Root Directory** to `backend`.
4. **Build Command**: `pip install -r requirements.txt`
5. **Start Command**: `python main.py`
6. **Environment Variables**:
   - `OPENROUTER_API_KEY`: Your key from OpenRouter.
   - `MODEL_ID`: (Optional) e.g., `openrouter/google/gemini-2.0-flash-exp:free`.

### Frontend Deployment (Vercel)
**Platform**: [Vercel.com](https://vercel.com/) (Hobby Tier)

1. Create a new project on Vercel.
2. Connect your GitHub repository.
3. Set the **Root Directory** to `frontend`.
4. **Environment Variables**:
   - `NEXT_PUBLIC_API_URL`: Your Render backend URL.

## 💡 Troubleshooting (macOS Specific)

### Colima & Docker Setup
For older Macs (e.g., 2017 MBP) that do not support Docker Desktop:
- Install Colima: `brew install docker docker-compose colima`
- Start with memory limits: `colima start --cpu 2 --memory 4`

### "Permission Denied" in Logs
If the frontend or backend shows permission errors writing to cache, ensure `docker-compose.yml` has anonymous volumes for `.next` and `node_modules`.

### "Port 8000 already in use"
```bash
lsof -ti:8000 | xargs kill -9
```

### Colima Won't Start
If Colima hangs:
```bash
colima delete  # WARNING: Deletes all images/containers
colima start --cpu 2 --memory 4 --vm-type qemu
```
